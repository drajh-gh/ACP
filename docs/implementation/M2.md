## Next local implementation slice

The next dependency is a dedicated filesystem-writer lease contract, not a new
use of the generic effect lease's expiry-based reacquisition. Bind exclusivity to
the retained physical workspace/common-directory identities and preserve exact
branch case in derived keys. An expired owner must retain exclusion until its
exact native launch is sealed and stopped; a timeout alone is not release proof.
Provisioning needs its own durable reservation before an admitted worker exists,
without fabricating a run to satisfy the existing run-owned foreign key. Verify
renewal loss, late owner writes, cancellation, stopped-owner recovery and
provisioning crashes in bounded disposable fixtures before enabling Git mutation.
No production host, credential or marketplace choice is needed to implement this
local prerequisite; deployment and live sandbox proof remain separate gaps.
