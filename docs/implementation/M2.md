## Next local implementation slice

The dedicated filesystem writer contract is now implemented separately from
generic effect leases, with bounded recovery inventory, one-shot native preflight
and cooperative/native renewal prerequisites. The trusted epoch controller and
bounded private Windows launcher channel preserve suspended identity before
process journaling, permit actual GO only after fresh database/native acceptance,
and await controller quiescence in public closure. Exact original persisted
launch metadata is required before spawning. The combined initial-epoch path is
now exercised with real PostgreSQL and native model-free processes. Standalone
linked-worktree identity pins now retain exact directory and structural pointer
handles while leaving intended content/index/ref updates possible (ADR0014).
They do not claim restricted access, reserved absence of
optional redirection files, hostile directory-metadata protection, or guaranteed
pin/stop ordering after abrupt owner death. Prove those separate boundaries
before delivery transport admission. Real-database periodic/cancellation coverage
now includes actual disposable workspace writes without claiming successful delivery.
The storage-only pre-run target hold now excludes conflicting metadata,
workspace and branch ownership without fabricating an admitted worker run
(ADR0015). It derives the exact existing selected dispatch generation and
workspace grant, but grants no filesystem or native creation authority. The next
prerequisite now records a separate immutable provisioner attempt with exact
target/base, a reported parent and a planned separate fence (ADR0017). That plan
is inert: a real permanent native fence, independent provisioner process/stop
journal and restricted parent/common-metadata authority are still required.
It cannot borrow the worker-run journal. Hold renewal cannot extend assignment
expiry, and a changed hold revision makes the captured plan recovery history.
Quiesce lease
renewals after confirmed tree closure but before recording a sealed stop: that
receipt intentionally ends owner renewal authority (ADR0010).
The native protocol now issues a one-use challenge and anchors expiry to its
native monotonic timestamp, not reply arrival (ADR0011). The trusted controller
must obtain a fresh exact-owner database ACK after that challenge, validate every
immutable lease field and increasing revision, and await native acceptance.
Uncertain database/native ACKs require stop, never a cached-duration retry or
freshly calculated deadline. Keep raw renewal frames private and do not treat
the native protocol alone as proof of a database commit. Preserve the distinction
between the no-longer-writing native tree and later durable stop/result/release.
A lease readback or preflight result is a historical
snapshot, not present permission or OS fencing. Keep shared physical Git metadata
exclusive and terminate owned writers on uncertain renewal, while retaining the
keys until sealed stop and terminal result validation. Provisioning now has its
own retained target hold, but still needs separately authorized native creation
and a gap-free conversion transaction. Verify actual late writes, renewal loss, native stop
recovery and provisioning crashes in disposable fixtures before enabling mutation.
No production host, credential or marketplace choice is needed to implement this
local prerequisite; deployment and live sandbox proof remain separate gaps.
