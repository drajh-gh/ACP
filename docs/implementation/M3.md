      shaped assessment contracts, leaving the legacy readiness DTO unchanged.

      absent observations remain unknown, positive expiry/evidence drift becomes
      stale, and expiry never clears revocation.
- [x] Preserve canonical UTC microseconds, exact expiry boundaries, explicit
      predecessor identity, unique sorted evidence IDs and a 24-hour validity cap.
- [x] Build one bounded metadata-only matrix from already-selected latest rows;
      deny invalid, restricted, cross-project or missing references as a whole.
- [x] Revalidate response identity and recompute state before accepting a matrix;
      never imply live probes, profile activation, grants or aggregate readiness.
- [x] Persist immutable exact assessment history and normalized server-derived
      evidence pins, with active provenance/binding admission and a default
      deferred commit guard in the private trusted producer.
- [x] Enforce exact predecessor compare-and-swap, unique root/predecessor/time
      constraints, physical transaction disposal and confirmed historical replay
      after same-ID races or uncertain COMMIT acknowledgement.
- [x] Read one bounded PostgreSQL snapshot using exact profile existence,
      latest-before-filtering selection and current evidence checks; expose
      identity drift separately from freshness/accessibility/hash metadata.
- [x] Make empty downgrade reversible while refusing removal of retained history.

The internal writer remains a trusted application boundary, not an evaluator-role
registry or model-facing tool. No readiness MCP tool is enabled yet. See
[ADR0019](../architecture/0019-recorded-capability-readiness.md) for the exact
contract, default-deferral/privileged-SQL caveat and remaining authority boundary.

  0017 and no live provider probes. Evidence includes concurrent roots/successors,
  repeatable-read denial, real lost-COMMIT readback and backend closure, same-
  transaction drift/retirement, forced early constraint checks, Unicode bounds,
  concurrent MVCC observations and history-preserving downgrade.
- Prior counterpart-status core (7) and inert provisioner-plan core (9) pass
  under 0017. All 20 migration-session checks pass, including apply/checksum replay/
  full reverse of all 17 actual migration pairs on an empty database.
- Strict TypeScript, all 391 local tests, secret scan and diff hygiene pass.
  Independent functional/specification and repository-conformance reviews pass;
  the final core rerun also verifies snapshot `2.0.0` through real storage. Reviewers
  did not rerun the main agent's sequential gates. No credentials, live models or
  external effects are involved; all disposable containers/process trees are owned,
