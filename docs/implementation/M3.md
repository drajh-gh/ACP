# M3 — Project profiles and onboarding

- Status: In progress; independent local work alongside unfinished M2.
- Specification: [1.0.0](../../SPECIFICATION.md), §13 and M3 milestone.

## Implemented domain foundation

- [x] Add exact project/profile/resource-scoped readiness query and immutable-
      shaped assessment contracts, leaving the legacy readiness DTO unchanged.
- [x] Retain all seven recorded states separately from derived current state;
      absent observations remain unknown, positive expiry/evidence drift becomes
      stale, and expiry never clears revocation.
- [x] Preserve canonical UTC microseconds, exact expiry boundaries, explicit
      predecessor identity, unique sorted evidence IDs and a 24-hour validity cap.
- [x] Build one bounded metadata-only matrix from already-selected latest rows;
      deny invalid, restricted, cross-project or missing references as a whole.
- [x] Revalidate response identity and recompute state before accepting a matrix;
      never imply live probes, profile activation, grants or aggregate readiness.

The first slice is pure domain code: it does not persist assessments, establish
writer authority or expose a new tool. See [ADR0019](../architecture/0019-recorded-capability-readiness.md)
for the exact contract and required durable follow-up.

## Verification

- Test-first readiness module import initially failed before implementation.
- Eleven focused local tests cover exact scopes, timestamp precision/date
  validity, all states, absence versus unconfigured, expiry/revocation, evidence
  deterioration, generic denial, metadata-only output, response substitutions
  and whole-response UTF-8 bounds.
- Strict TypeScript, full local suite (385 tests), secret scan and diff hygiene
  pass. No provider credentials, live models or external effects are involved.
- Independent exact-source functional/specification and repository-conformance
  reviews pass. Reviewers did not rerun the main agent's sequential gates.
