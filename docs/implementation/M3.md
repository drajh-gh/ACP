      shaped assessment contracts, leaving the legacy readiness DTO unchanged.
- [x] Retain all seven recorded states separately from derived current state;
      absent observations remain unknown, positive expiry/evidence drift becomes
      stale, and expiry never clears revocation.
- [x] Preserve canonical UTC microseconds, exact expiry boundaries, explicit
      predecessor identity, unique sorted evidence IDs and a 24-hour validity cap.
- [x] Build one bounded metadata-only matrix from already-selected latest rows;
      deny invalid, restricted, cross-project or missing references as a whole.
- [x] Revalidate response identity and recompute state before accepting a matrix;
      never imply live probes, profile activation, grants or aggregate readiness.
- [x] Persist immutable exact assessment history and normalized server-derived
      evidence pins, with active provenance/binding admission and a default
      deferred commit guard in the private trusted producer.

      constraints, physical transaction disposal and confirmed historical replay
      after same-ID races or uncertain COMMIT acknowledgement.
- [x] Read one bounded PostgreSQL snapshot using exact profile existence,
      latest-before-filtering selection and current evidence checks; expose
      identity drift separately from freshness/accessibility/hash metadata.
- [x] Make empty downgrade reversible while refusing removal of retained history.
- [x] Expose authenticated read-only `get_project_readiness` with strict input,
      exact schema-2 response validation and constant whole-tool error masking.
- [x] Add the tool to the repository-local counterpart package and document
      observation-versus-authority boundaries; advertise control/plugin `0.2.0`
      while preserving default `0.1.0` compatibility and explicit operator lists.
